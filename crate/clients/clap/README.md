# Cosmian KMS CLI Actions

This crate is used for testing the KMS server, and provides shared `clap` command implementations for the [CLI repository](https://github.com/Cosmian/cli).

For production use, install the CLI from [Cosmian packages](https://package.cosmian.com/kms/), `cargo install ckms`, or [GitHub releases](https://github.com/Cosmian/cli/releases). Full docs: [docs.cosmian.com](https://docs.cosmian.com/cosmian_cli/).
