# Dependencies for update_readme_kmip.py.
#
# Without beautifulsoup4, the script silently falls back to a hardcoded,
# less accurate dataset (get_fallback_version_data), which produces
# different (flaky) KMIP support tables in README.md / support.md depending
# on whether the running environment has this package installed.
# Always install this before running `mise run docs:generate` or
# `python3 .mise/scripts/docs/update_readme_kmip.py` to keep generated
# documentation deterministic.
