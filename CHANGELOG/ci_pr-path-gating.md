## CI

- Run each pull-request CI unit only when files related to it changed, without any "skipped" row in the run graph. Every single-job unit is now its own workflow with a `pull_request: paths:` trigger (so GitHub creates no run, and no row, when no matching file changed) and a `workflow_call` trigger: `clippy.yml`, `machete.yml`, `no-nix.yml`, `forward_proxy.yml`, `build-documentation.yml`, `cargo-publish-dry-run.yml`, `xks-remote.yml`, `test-cloud.yml`, `test-ui.yml`, `test-pki-macos.yml` and `windows-cargo-test.yml`, `windows-ui.yml`, `windows-cng-ksp.yml`, `windows-hsm-idemia.yml`, `windows-est.yml` (replacing `test_windows.yml`). Each cancels its own previous run per PR.
- Split the pipeline by trigger. `pull-request.yml` runs on pull requests only (`changes`, `Security Audit`, `supply-chain`, and the `test` call); `main.yml` now runs tags, the nightly schedule and manual dispatch only, calls every unit workflow, `test_all.yml` with the full suite matrix, the real-HSM `test-hsm-hardware` job and `cargo-publish`, and no longer has any gating or the unused `cla-assistant` job.
- Classify only the suites that share `test_all.yml`. `.github/ci-paths.toml` keeps the units `db:*`, `interop:*`, `hsm`, `pkcs11`, `obs`, `pki` and `spire`; each lists its `variants` (and `bench` models for `hsm`). `mise run dev:ci-changes` (`.mise/scripts/dev/ci_changes.py`) outputs `skip`, `suites-matrix` (the legs of the running units) and `run-test`; `--all` (tags, nightly, dispatch) emits every leg. The `test-suites` job of `test_all.yml` takes its legs from that matrix, so a suite that does not run has no row, and the `test` job of `pull-request.yml` is a single skipped row only when no suite runs. Any `crate/**` change still runs `db:sqlite`, code linked into the server also runs `spire`, and a change to `full` files or to a file listed nowhere runs every suite; the inputs of the single-job workflows are listed in `ignore` so they never run the suites.
- Move the Nix dev-shell cache into `nix-dev-shell-cache.yml`, called by `test_all.yml`, `test-cloud.yml` and `test-ui.yml`, and drop `workflow_dispatch` and the `skip-units` inputs from `test_all.yml`.
- Document the workflows in `.github/workflows/README_main.md`; `mise run dev:ci-changes --self-test` runs the classifier tests against the real config.
