## CI

- Run each pull-request CI job only when files related to it changed. `.github/ci-paths.toml` lists, per CI unit (clippy, machete, no-nix, forward-proxy, publish dry run, XKS remote, every `test-group.yml` suite, the Windows jobs and the macOS PKI job), the regexes of the files that trigger it; the new `changes` job of `main.yml` runs `mise run dev:ci-changes` (`.mise/scripts/dev/ci_changes.py`) and passes the skipped units down as `skip-units` to `test_all.yml`, `test-db.yml`, `test-interop.yml`, `test-group.yml` and `test_windows.yml`. Any `crate/**` change still runs the whole-workspace jobs (clippy, machete, no-nix, publish dry run, `db:sqlite`, Windows `cargo test`); code linked into the server also runs `spire`, `xks-remote` and `forward-proxy`. The other suites (`ui`, `interop:*`, `pki`, `pkcs11`, `obs`, `hsm`, `cloud`, `db:*` other than sqlite, and the Windows mirrors) run only on their own crates, paths and test scripts: the database suites on `server_database`, the KMIP interop suites on `kmip` and the `/kmip` route. A change to `main.yml` or `test_all.yml` runs only the units defined in or called directly by it, and one to `test-interop.yml` runs `interop:pykmip`; `no-nix.yml`, `test_windows.yml`, `cargo_test.ps1`, `test-db.yml`, `test-group.yml`, `ci-paths.toml` and `ci_changes.py` run no suite, so `no-nix` and the Windows `cargo test` need a Rust source change. A changed file that matches no unit and is not ignored, a file matching `full`, or an empty diff runs everything, as do tags, the nightly schedule and manual dispatch.
- Show fewer skipped rows in the pull-request run graph. `ci_changes.py` now also emits `db-matrix`, `interop-matrix` (the running legs, from the `variants` of each `db:*` / `interop:*` unit in `ci-paths.toml`) and `run-test` / `run-windows` (from its `[callers]` table); `test-db.yml` and `test-interop.yml` build their matrix from them, `test_all.yml` gates each suite job itself (`test-group.yml` no longer takes `skip-units`), and `main.yml` skips the whole `test` or `windows` call, as one row, when none of its units runs. `test_all.yml` loses its `workflow_dispatch` trigger (dispatch `main.yml`; `mise run dev:ci-changes --all` emits the full matrices for non-PR events).
